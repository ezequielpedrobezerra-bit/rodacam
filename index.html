—
Limite do iPhone: nenhum app grava com a tela desligada ou em segundo plano — o iOS corta a câmera. A "Tela escura" deixa a tela preta mas acesa, em primeiro plano. Para gravar muito tempo, use energia do carro e, de preferência, o Acesso Guiado (Ajustes → Acessibilidade) para travar no app.
Os clipes ficam só neste iPhone, dentro do Safari. Limpar os dados do site apaga tudo. Para guardar um clipe importante, use Salvar/Compartilhar na aba Clipes.
